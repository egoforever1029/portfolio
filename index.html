Fullstack архитектура

СпецТехАренда — Сервис аренды спецтехники

Архитектурный стек и безопасность:

  • REST API сервер: Построен на Express.js, реализует чистые HTTP-маршруты для каталога, аутентификации, бронирования и администрирования.
  • Безопасность JWT & Cookies: Токены авторизации генерируются с секретным ключом и передаются через HttpOnly cookies, предотвращая XSS-атаки.
  • Хэширование паролей: Защита учетных записей с помощью bcryptjs (соление и стойкое шифрование).
  • База данных SQLite3: Таблицы users, machinery, bookings с валидацией целостности данных и внешними ключами.
  • Ролевая модель доступа (RBAC): Разделение привилегий клиентов (оформление заказа, история в профиле) и администраторов (управление техникой, изменение статусов заявок).

Основные API эндпоинты:

POST /api/auth/register # Регистрация пользователя с хэшированием POST /api/auth/login # Вход, выдача JWT токена GET /api/auth/me # Проверка активной сессии GET /api/machinery # Получение каталога техники с фильтрацией POST /api/bookings # Создание бронирования с валидацией дат GET /api/bookings/my # Получение заказов текущего пользователя GET /api/admin/bookings # Полный мониторинг заказов для администратора PATCH /api/admin/bookings/:id # Обновление статуса (подтвержден/отклонен)
